NoCodeMotion · Lua 脚本使用说明书

适用版本：V1.0 运行环境：Windows · .NET 10 Lua 引擎：MoonSharp（Lua 5.2） 面向真实设备控制

本说明书能做什么

NoCodeMotion 的「脚本流程」使用 Lua 5.2 语言（MoonSharp 引擎）编写控制逻辑。脚本运行在后台线程，可直接驱动真实设备：运动控制卡（雷赛）、输入/输出 IO、气缸、串口/网口通讯（含 Modbus）、料盘，并与工程变量表、运行控制（启动/暂停/继续/停止/急停）深度联动。

本文档所有 API、示例与运行行为均对照软件内 HardwareApi 注册表、Lua 编辑器智能提示与内置工程模板整理，可直接照抄使用。

1.1 脚本在框架中的位置

一个「脚本流程」就是一个 Lua 源码块（FlowItem.LuaSource）。工程可同时包含多类流程：

流程类型编辑方式适用场景
脚本流程（Lua）代码编辑器复杂逻辑：条件分支、循环、配方切换、轴联动、与 PLC 通讯
表格流程DataGrid 行式步骤简单顺序动作：轴定位、IO 置位、气缸动作、延时
视觉流程图形节点图像采集、模板匹配、缺陷检测、测量、对位、标定
复位流程与主流程相同复位动作序列（点击「复位」时执行）
运行方式：Lua 脚本由 MoonSharp 逐行解释执行，print() 输出实时显示在编辑器的「输出面板」。脚本内部调用硬件函数（如 Axis.MoveAbs）时，框架先按名称从工程配置解析出设备对象，再交给真实硬件桥执行；设备未连接时交给仿真桥执行。

1.2 能力总览

能力说明状态

2快速上手（真实设备）

2.1 硬件准备

  1. 连接控制卡：安装雷赛控制卡驱动（LTDMC），插好 PCI/PCIe 卡。软件在「控制器」页面自动检测卡数量与型号。
  2. 配置设备：在「轴」「IO」「气缸」「通讯」「料盘」页面按实际接线填写名称、卡号、位号、速度、正负限位等参数。名称是脚本引用的唯一凭据，脚本里写什么名字，配置页就必须有同名的设备。
  3. 切换到真实硬件：默认处于仿真模式。点击切换到真实硬件（或脚本内调用 UseRealHardware()），状态栏显示「雷赛控制卡已连接」即就绪。
  4. 新建脚本流程：在「流程」页面新建流程，类型选「脚本」，进入 Lua 编辑器编写代码。
提示：真实设备调试前，建议先用 UseSimulation() / 仿真模式把逻辑跑通一遍，再切换真实硬件。仿真模式下未配置的输入 IO 默认返回 "1"，方便直接跑通等待信号的逻辑。

2.2 第一个脚本

复制下面的脚本到 Lua 编辑器，F5 运行（F5 运行，F10 单步，F9 断点）：

示例 · 等待启动 → 轴运动 → 气缸 → 完成
-- 等待启动信号（输入 IO「启动」= 1）
while IO.Get('启动') ~= '1' do
    WaitStep(50)            -- 每 50ms 查一次
    if EStop() then return end  -- 急停立即退出
end

IO.Set('运行', '1')          -- 输出 IO「运行」置 1

-- 轴绝对定位：X 到 100，速度 800
Axis.MoveAbs('X', 100, 800)
Axis.WaitDone('X')          -- 等待到位

-- 气缸伸出，等感应到位
Cylinder.Out('夹紧')
WaitCylinder('夹紧')

-- 延时 300ms 后缩回
Delay(300)
Cylinder.Back('夹紧')

IO.Set('完成', '1')          -- 输出 IO「完成」置 1
Print('本循环完成')
注意：以上用到的设备名（启动、运行、X、夹紧、完成）必须在工程配置页中真实存在，否则运行时报错「找不到轴：XXX」并显示在输出面板。

2.3 运行与停止

  • 运行：编辑器工具栏「运行」或 F5；操作员页面「启动」按工程流程并发执行。
  • 暂停 / 继续：编辑器或操作员页面均可暂停；暂停后按钮变「继续」，恢复执行。
  • 停止：当前步骤完成后退出循环，状态置「已停止」。
  • 急停：立即切断所有运动输出，进入急停锁定；必须先「复位」才能再次启动。脚本内用 EStop() 主动检测。

4硬件函数 API（全局函数）

以下 28 个函数由框架注册为 Lua 全局函数，编辑器右侧「智能插入」面板可一键插入（并带中文注释与可直接改的数值）。调用时设备名必须与工程配置一致；找不到设备只给「提示」并跳过该条指令，不会抛异常、也不会让脚本崩溃。

智能插入面板：左列按功能分组 —— 逻辑结构 / 程序控制（急停检查、主循环、循环 N 次、等待输入含超时、条件分支）/ 日志（Info/Warn/Error/Debug、分隔行）/ 延时 / 轴 / IO / 气缸 / 点位 / 变量（设置数值、设置文本、读取、累加、加减、清零、判断、当作轴目标位置） / 通讯 / 料盘 / 硬件状态。右侧列表按所选功能给出对应名称（点位为「点位表名.点位名」）或可插入代码块，底部实时预览将插入的代码，插入后直接改数字即可运行。

4.1 轴运动

函数说明
AxisMove(name)驱动轴运动到配置页设定的目标位置（配合点位使用）
MoveAxisAbs(name, position)轴运动到绝对位置 position（使用轴当前速度）
MoveAxisRel(name, distance)轴相对当前位置移动 distance（可负值）
SetAxisSpeed(name, speed)设置轴运行速度，后续移动生效
AxisHome(name)轴回零（找原点）
StopAxis(name)立即停止该轴
WaitAxisDone(name)阻塞等待轴到位（运动完成才返回）
EnableAxis(name)轴使能 / 解除使能（切换伺服使能）

4.2 IO 读写

函数说明
ReadIO(name)读取输入 IO，返回 0 / 1（number）
WaitIO(name, value)阻塞等待输入 IO 变为 value（0 或 1）
SetIO(name, value)设置输出 IO 电平 value（0 或 1）
ToggleIO(name)输出 IO 电平取反

4.3 气缸

函数说明
CylinderMove(name, state)气缸动作：state=1 伸出 / 0 缩回
WaitCylinder(name)阻塞等待气缸到位（按感应点轮询）
CylinderReset(name)气缸复位到初始状态

4.4 通讯

函数说明
CommSend(name, data)发送数据：普通文本直接发；"HEX:02 41 42 03" 按十六进制字节发；Modbus 通道用命令语法（见第 6 章）
CommRecv(name)接收数据并返回字符串；Modbus 通道返回上一条读命令的结果（逗号分隔）

4.5 料盘

函数说明
TrayPick(name)料盘取料（按当前取料位执行）
TrayPlace(name)料盘放料

4.6 点位（点位表 / 点位）

点位按「点位表名.点位名」引用（如 PointMove("工位1.取料点")）；只写点位名时会跨表查唯一匹配。点位表每个点位含 4 个轴槽（轴 + 目标位置 + 速度），在「点位」页面配置。

函数说明
PointMove("点位表.点位名")点位移动：按点位表各轴槽把轴真正开到该点位（未填目标位置的轴槽跳过、不改动该轴），阻塞到各轴到位；返回驱动的轴数
PointModify("点位表.点位名", 轴槽, 位置, 速度)点位修改：把第 N 个轴槽（1~4）的目标位置改成指定值（速度填 0 表示不改速度），真实写回工程并自动保存
PointTeach("点位表.点位名")点位示教：把各轴当前位置写成该点位的目标位置（现场开到位置后示教），真实写回工程并自动保存
例：现场手动把 X/Y 开到理想位置后执行 PointTeach("工位1.取料点")，该点位的坐标即被当前实际位置覆盖并落盘；后续运行 PointMove("工位1.取料点") 就会走到示教出来的位置。

4.7 硬件状态与模式

函数说明
HardwareStatus()返回当前硬件对接状态（中文），如「雷赛控制卡已连接（卡数量 1）…」
HardwareReady()控制卡是否就绪：1 就绪 / 0 未就绪
HardwareReconnect()重新连接控制卡（现场插好卡 / 装好驱动后调用），返回中文结果
UseRealHardware()切换到真实硬件（雷赛控制卡 + 真实串口/网口/Modbus），返回中文结果
UseSimulation()切换到仿真模式（不驱动任何设备，只打印日志），返回中文结果

4.8 运行控制与辅助

函数说明
EStop()当前是否急停锁定（返回 boolean）。脚本循环里 if EStop() then return end 及时退出
Delay(ms)脚本内延时（毫秒），范围 0~60000，在后台线程休眠
WaitStep(ms)与 Delay 等价的别名，语义为「每步停顿」，模板中使用
Print(...)大写别名，输出到输出面板（标准 print 同样可用）

5命名空间 API

除全局函数外，框架提供 4 个命名空间表，写法更接近面向对象，推荐在脚本流程中使用：

5.1 Variable — 工程变量表

函数说明
Variable.Get(name)读变量：可解析为数字时返回 number，否则返回 string；未定义返回 nil
Variable.Set(name, value)写变量（数字或字符串皆可），自动在变量表查找/新建，并实时打印 [变量] name = value
示例 · 配方切换
local recipe = Variable.Get('当前工序') or 'A'
if recipe == 'A' then
    Variable.Set('缺陷阈值', 0.95)
elseif recipe == 'B' then
    Variable.Set('缺陷阈值', 0.90)
else
    Print('未知配方：' .. recipe)
end
提示：变量表数据绑定到「变量页面」表格，Variable.Set 会自动在 UI 线程同步执行，保证线程安全；紧跟其后的 Variable.Get 一定能读到新值。

5.2 IO — 输入 / 输出

函数说明
IO.Get(name)读输入 IO，返回字符串 "0" / "1"。仿真且未配置该输入时返回 "1"
IO.Set(name, value)写输出 IO（值自动解析为整数）；找不到该输出时给出警告而非崩溃

与全局函数的关系：IO.Get 等价 ReadIO 的字符串版（IO.Get(x) == '1' 即 ReadIO(x) == 1）；IO.Set 等价 SetIO，但参数更宽容、找不到设备只警告。

5.3 Axis — 轴

函数说明
Axis.MoveAbs(name, position, speed)设置速度后运动到绝对位置（一步完成）
Axis.MoveRel(name, distance)相对移动
Axis.Home(name)回零
Axis.Stop(name)立即停止
Axis.WaitDone(name)阻塞等待到位
Axis.SetSpeed(name, speed)设置速度
Axis.Enable(name)使能

5.4 Cylinder — 气缸

函数说明
Cylinder.Out(name)伸出（等价 CylinderMove(name, 1)）
Cylinder.Back(name)缩回（等价 CylinderMove(name, 0)）
Cylinder.Reset(name)复位到初始状态

6通讯与 Modbus

「通讯」配置页的设备（串口 / 网口 / ModbusRTU / ModbusTCP）统一通过 CommSend / CommRecv 访问。发送内容分三种形态：

6.1 三种发送形态

形态写法说明
纯文本CommSend('PLC1', 'READY')按 ASCII 字节直接发送
十六进制CommSend('PLC1', 'HEX:02 41 42 03')HEX: 前缀，允许空格/逗号/0x 前缀，按字节发送（适合帧头帧尾、CRC 等不可见字节）
Modbus 命令CommSend('PLC1', 'RH,1,0,2')ModbusRTU / ModbusTCP 通道专用命令语法（见下）

6.2 Modbus 命令一览

命令功能格式Modbus 功能码
RH读保持寄存器RH,站号,起始地址,数量03
RI读输入寄存器RI,站号,起始地址,数量04
RC读线圈RC,站号,起始地址,数量01
RD读离散输入RD,站号,起始地址,数量02
WH写保持寄存器WH,站号,地址,值（多值逗号分隔）06 / 16
WC写线圈WC,站号,地址,值（0/1）05 / 15

命令大小写不敏感；读命令用 CommRecv 取结果，返回逗号分隔字符串（如 "100,200"、"1,0,0,1"）。

示例 · 读写 PLC 寄存器
-- 读保持寄存器：站号 1，地址 0，读 2 个
CommSend('PLC1', 'RH,1,0,2')
local v = CommRecv('PLC1')        -- 例 "100,200"
local t1 = tonumber(v:split(',')[1])

-- 写单个保持寄存器：站号 1，地址 10，值 1234
CommSend('PLC1', 'WH,1,10,1234')

-- 写线圈：站号 1，地址 5，置 1
CommSend('PLC1', 'WC,1,5,1')

-- 读离散输入 4 个
CommSend('PLC1', 'RD,1,0,4')
local s = CommRecv('PLC1')        -- 例 "1,0,0,1"
接线提醒：ModbusRTU 走串口（配置页填 COM 口 + 波特率），ModbusTCP 走网口（填 PLC 的 IP，端口默认 502）。连接超时、串口被占用、地址不通都会给出中文错误提示。

7真实设备示例

以下示例均使用已注册 API，可直接复制到 Lua 编辑器调试。设备名请替换为工程中实际配置的名称。

7.1 完整取放流程（料盘 + 轴联动 + 气缸 + 视觉工位等待）

示例 · 单循环取放
-- ===== 上料段 =====
TrayPick('上料盘')                -- 料盘取料

-- X/Y 轴联动走矩形（绝对定位，速度 800）
Axis.MoveAbs('X', 0, 800)
Axis.MoveAbs('Y', 0, 800)
WaitStep(200)
Axis.MoveAbs('X', 100, 800)
Axis.MoveAbs('Y', 0, 800)
WaitStep(200)
Axis.MoveAbs('X', 100, 800)
Axis.MoveAbs('Y', 100, 800)
WaitStep(200)
Axis.MoveAbs('X', 0, 800)
Axis.MoveAbs('Y', 100, 800)
WaitStep(200)

-- ===== 夹紧段 =====
Cylinder.Out('夹紧')
WaitCylinder('夹紧')              -- 等感应到位
Delay(300)
Cylinder.Back('夹紧')

-- ===== 放料段 =====
TrayPlace('下料盘')

IO.Set('完成', '1')               -- 通知下位机本循环完成
Print('单循环完成')

7.2 等待外部启动信号的主循环

设备「启动」按钮接入输入 IO 时，脚本流程可用此模式等待启动；循环内每步都检查急停：

示例 · 启动信号循环
local cycle = Variable.Get('循环数') or 0

while true do
    -- 等待启动信号（输入 IO「启动」为 1）
    while IO.Get('启动') ~= '1' do
        WaitStep(50)
        if EStop() then return end
    end

    cycle = cycle + 1
    Variable.Set('循环数', tostring(cycle))

    IO.Set('运行', '1')

    -- …… 此处写实际工艺动作 ……
    Axis.MoveAbs('X', 50, 600)
    Axis.WaitDone('X')

    IO.Set('完成', '1')
    IO.Set('运行', '0')
end

7.3 配方 / 参数切换

示例 · 依据变量选择工艺参数
local recipe = Variable.Get('当前配方') or 'A'

if recipe == 'A' then
    SetAxisSpeed('X', 800)
    Variable.Set('缺陷阈值', 0.95)
elseif recipe == 'B' then
    SetAxisSpeed('X', 400)
    Variable.Set('缺陷阈值', 0.90)
else
    Print('未知配方：' .. recipe)
    return false      -- 结束本轮，流程进入异常/停止分支
end

Axis.MoveAbs('X', 100, 800)

7.4 复位脚本

复位流程（Role = 复位）在点击操作员页「复位」时执行，用于把设备恢复初始姿态：

示例 · 设备复位
-- 气缸全部缩回
Cylinder.Back('夹紧')
Cylinder.Back('顶升')

-- 轴回零
Axis.Home('X')
Axis.WaitDone('X')
Axis.Home('Y')
Axis.WaitDone('Y')

-- 输出复位
IO.Set('运行', '0')
IO.Set('完成', '0')
Print('复位完成')

7.5 视觉配合（通过视觉流程）

视觉能力（图像采集、模板匹配、缺陷检测、测量、对位、标定）由「视觉流程」图形节点承载，内部调用 VisionEngine 真算子（OpenCvSharp + 旋转不变 NCC 匹配）。Lua 脚本与视觉流程的衔接方式：

  • 视觉流程把结果写入工程变量（如「匹配分数」「X」「Y」「R」），Lua 用 Variable.Get 读取判断。
  • 视觉流程可把结果通过通讯发给下位机（Target 内容支持 {变量名} 占位符）。
  • Lua 侧目前未注册 Camera.Grab / Vision.Match / Vision.Defect / Log.* 等命名空间（处于规划中）。请不要在脚本流程中直接调用它们，否则会报「attempt to index a nil value」。视觉业务请走视觉流程图形节点。

8运行控制与异常

8.1 运行状态机

空闲→ 运行中→ 暂停中↔ 运行中
运行中→ 异常→ 已停止
状态触发条件说明
空闲未运行 / 正常结束可启动
运行中点「启动 / 继续」暂停 / 停止 / 急停按钮可用
暂停中点「暂停」Lua 会话挂起，按钮变「继续」可恢复
异常脚本报错 / 硬件异常 / 超时停止重试，提示行号与错误信息，需修正脚本后重新启动
已停止点「停止」或「急停」本轮结束，KPI 不清零

8.2 暂停 / 继续 / 停止 / 急停

  • 暂停：运行中随时可点。Lua 会话在安全点挂起（脚本循环 WaitStep / 步骤边界），界面按钮变为「继续」。
  • 继续：恢复挂起的会话继续执行。
  • 停止：请求当前步骤结束后退出循环，状态置「已停止」。
  • 急停：立即切断所有运动输出（轴停止、IO 复位、气缸缩回），进入急停锁定；锁定期间所有运行按钮灰显，必须点「复位」解锁。脚本内可用 EStop() 主动检测并提前 return。

8.3 脚本异常处理

  • 找不到设备（轴 / IO / 气缸 / 通讯 / 料盘 / 点位名称不匹配）：不抛异常，输出面板给一条橙色「提示」（如「[提示] 未找到输入 IO「X0」：请到「IO」页添加同名输入点…本条指令已跳过。」），该条指令安全跳过、脚本继续执行。同一条提示只出现一次，不会在循环里刷屏。
  • 硬件未就绪（没连控制卡）：同样只提示「[提示] 硬件未就绪：请到「控制器」页连接控制卡（或选虚拟卡 / 仿真）后再运行。」并跳过运动类指令。
  • 脚本语法 / 运行错误：输出面板显示错误信息与行号，流程状态置「异常」，停止重试（避免日志刷屏）。
  • 防死循环：表格流程有步骤执行数上限保护；Lua 循环建议每轮 WaitStep(ms) 让出节奏并检查 EStop()。
  • 建议写法：工艺关键处用 if EStop() then return end；等待外部条件用 WaitIO / IO.Get 轮询 + 急停检查，而不是空转死等。

10注意事项与限制

10.1 名称解析

  • 脚本中所有设备名（轴 / 输入 IO / 输出 IO / 气缸 / 通讯 / 料盘 / 点位「表名.点名」）必须与工程配置页名称完全一致，区分大小写。
  • 找不到设备不再让脚本崩溃：输出面板给橙色「提示」说明该去哪一页补配置，本条指令跳过、脚本继续跑（同一条只提示一次）。真正的脚本语法 / 运行错误（如调用 nil、类型不对）才会把流程置「异常」。

10.2 行为细节

  • Delay(ms) 范围 0 ~ 60000 ms，超出自动截断。
  • IO.Get 在仿真且未配置该输入时返回 "1"，保证纯仿真脚本可跑通等待逻辑；接真实硬件后以真实电平为准。
  • 所有硬件函数（含 ReadIO / WaitIO / SetIO、轴 / 气缸 / 通讯 / 料盘 / 点位）找不到设备或硬件未就绪时都是橙色「提示」+ 跳过本条指令，不再抛异常：读类函数返回安全默认值（ReadIO → 0、CommRecv → 空串、点位类 → 0），等待类函数（WaitIO / WaitAxisDone / WaitCylinder）立即返回，避免「永远等不到」。
  • Variable.Get：可解析为数字返回 number（可用算术运算），否则返回 string，未定义返回 nil——用 or 给默认值（如 Variable.Get('循环数') or 0）。
  • 变量表绑定 UI 表格，Variable.Set 自动切到 UI 线程写入，线程安全；不要在脚本里直接修改 ProjectStore 之外的框架对象。
  • 仿真模式下 Axis.WaitDone 立即返回；真实模式下按卡到位信号阻塞等待。
