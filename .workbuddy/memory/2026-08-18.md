## UI 全局美化 + 图标体系
用户要求“全部颜色都美化，尽量都加上图标”。在 NoCodeMotion（WPF/.NET10/HandyControl）实施了一套统一主题：

- **`App.xaml` 集中改造**：
  - 调色板：引入 Color + SolidColorBrush（Accent / AccentSoft / Canvas / Surface / Line / Text* / Success / Danger / Warning），语义化命名，全站引用。
  - 柔和阴影：`SoftShadow` / `SoftShadowSm`（DropShadowEffect）。
  - **矢量图标集**：`Geometry` 资源（24x24 Material 风格路径）—— 导航 7 个（Axis/Io/Cylinder/Comm/Tray/Flow/Variable），工具栏 9 个（Excel/Add/Delete/Up/Down/Copy/Paste/Undo/Redo），分组标题 1 个（SectionIcon）。
  - 隐式样式：`Style TargetType="DataGrid"`（白底卡片 + 圆角边框 + 阴影 + 统一表头 `GridHeaderStyle`）、`Style TargetType="ListBoxItem"`（悬停/选中高亮，选中=Accent 底白字）。
  - 按钮样式统一圆角 8、悬停/禁用色，Tt* 工具栏按钮红/绿/蓝语义色。
- **导航栏 `MainWindow.xaml` + `.cs`**：7 个按钮改为「图标 + 文字」StackPanel，`Path.Fill` 绑定 `AncestorType=Button` 的 Foreground；`Navigate()` 增加 Foreground 切换（选中=白字，未选=深色），图标随状态变色；内容区背景改为 Canvas 画布。
- **`TableToolbar.xaml`**：9 个按钮全部加图标（Excel/增/删/上移/下移/复制/粘贴/回撤/重做）。
- **`EditorPage.xaml`**：添加/删除按钮加图标，计数文字改用 TextSecondaryBrush。
- **分组/分区标题加图标**：AxisPage(5) / TrayPage(2) / IoPage(2 输入/输出IO) / CylinderPage / CommPage / FlowPage 的分区标题统一改为 `SectionHeaderStyle`（SectionIcon + 加粗 Accent 文字）；原 `GroupHeaderStyle`/`IoSectionTitleStyle` 已不再使用（保留无害）。
- **表格细节**：IoHeaderStyle / VarHeaderStyle 改为 AccentSoft 底 + Accent 2px 下边框；IoRowStyle / VarRowStyle 加悬停高亮；IoPage / VariablePage 背景改 Transparent 以露出 Canvas 画布，DataGrid 成白色卡片。
- 构建：0 警告 0 错误。

**经验**：WPF 轻量图标方案 = 在 App.xaml 定义 `<Geometry x:Key>` 资源，按钮/标题里用 `<Path Data="{StaticResource ...}" Fill="{Binding RelativeSource={RelativeSource AncestorType=Button},Path=Foreground}"/>`，图标即可随按钮前景色（含选中态）自动变色，无需图标字体。隐式 `TargetType` 样式可全局统一 DataGrid/ListBox 外观，但其中若 `StaticResource` 引用了定义在更后面的键，需改用 `{DynamicResource}` 避免前向引用报错。

## 单元格 ComboBox 彻底扁平化（修复"还是很丑"）
- 根因：`hc:ComboBox`(HandyControl) 自带模板含边框+默认箭头，之前用 `BorderThickness=0`/`Background=Transparent` 的 setter 无法真正去掉其内部边框/箭头，所以仍显"丑"。
- `App.xaml` 新增共享 `CellComboStyle`（TargetType=ComboBox）：**完全自定义 ControlTemplate**——平时透明、悬停/展开时 AccentSoft 浅填充、右侧干净 chevron（Path）、下拉面板为白色圆角卡片(6)+LineBrush 边框+SoftShadow 阴影+高亮项(ComboBoxItem 模板)。关键命名部件：`PART_Popup`(Popup)、`PART_ContentSite`(ContentPresenter)，保证下拉可开、选中项可显示。
- `Views/FlowPage.xaml`：6 处 `hc:ComboBox` 改为 `<ComboBox Style="{StaticResource CellComboStyle}">`；删除本地 `FlowCellComboStyle`；`FlowCellTextBoxStyle` 增加悬停/聚焦浅强调背景(Style.Triggers)。
- `Views/IoPage.xaml`：4 处同步改为 `CellComboStyle`，删除本地 `IoCellComboStyle`（保持 Io/Flow 两页一致）。
- 构建 0 警告 0 错误，App 启动无异常。

## 新增「点位表」页（轴的点位，供流程引用）
- 用户要求：在气缸后面加一个「点位表」页面，定义为轴的点位（命名位置，含各轴目标坐标），方便流程使用。
- **数据模型**：
  - `Models/PointAxis.cs`：单个轴坐标（AxisName + Position(double)，实现 INotifyPropertyChanged）。
  - `Models/PointItem.cs`：`: EditorItemBase`，`ObservableCollection<PointAxis> Positions`（get-only，JSON 反序列化填充已有集合）；构造里订阅 `Positions.CollectionChanged`，并对每个 PointAxis 订阅 `PropertyChanged` → 冒泡为 PointItem 的 PropertyChanged，使列表 VM 的自动保存能捕获坐标编辑。
- **接入全局**：`Services/Catalog.cs` 加 `PointNames` + `SetPoint` + `RebuildAll`/`SyncAllFromData` 纳入；`Models/ProjectData.cs` 加 `Points`；`ViewModels/ListEditorViewModel.cs` 的 `SyncCatalog` switch 加 `"Point"` 分支（CatalogCategory="Point" 即把点位名汇入 Catalog）。
- **页面**：`ViewModels/PointViewModel.cs`（`: ListEditorViewModel<PointItem>, IEnsureDefaultSelection`；`CreateNewItem` 按当前 `Catalog.AxisNames` 给每个轴初始化一行坐标）；`Views/PointPage.xaml`（`EditorPage` + 右详情：点位名称 + `ItemsControl` 绑定 `SelectedItem.Positions` 渲染各轴坐标 TextBox）+ `PointPage.xaml.cs`（`DataContext=new PointViewModel()`）。
- **导航/图标**：`App.xaml` 加 `PointIcon`（靶心几何）；`MainWindow.xaml` 气缸按钮后插 `点位表` 按钮(Tag="Point")；`MainWindow.xaml.cs` `_pages` 加 `["Point"]=()=>new PointPage()`。
- **流程引用**：`Views/FlowPage.xaml` 的 `FunctionOptions` 加 `点位`；`FunctionToNamesConverter` 加 `"点位"=>Catalog.PointNames`（名称列即可选点位名）；`FunctionToPropertiesConverter` 加 `["点位"]=速度/加速度/到位误差/是否等待到位`。
- **注意**：点位坐标在新建时按当时已配置轴生成；之后若增删轴，旧点位不会自动增删轴（重新建点位即可）。`SelectedItem` 为空时详情的 `SelectedItem.Positions` 绑定为 null，ItemsControl 仅空，不报错。
