## 工程师页 ComboBox 显示类名 + 全员水印

### 1. 工程师页 ComboBox 显示类名（"NoCodeMotion.Models.PointTat" 截图）
- **根因**：`Views/EngineerPage.xaml` 第 280-281 行 ComboBox 用 `DisplayMemberPath="Name"` + `Style="{StaticResource CellComboStyle}"`（`CellComboStyle` 强制 `IsReadOnly=True`）。
  当 `EditorItemBase.Name` 在某些路径（WPF 反射解析 / ItemContainerStyle 模板 / `IsReadOnly` 嵌入 TextBox）下被 binding 解析成 `null` 时，WPF 会回退调用 `object.ToString()`，于是显示 `NoCodeMotion.Models.PointTable` 全类型名。
- **修法（两道闸口）**：
  1. `Models/EditorItemBase.cs` —— 重写 `ToString()`：`null/空白 → "未命名"`，否则返回 `Name`。任何 binding 失败路径下都不再泄露类型名（也救回日志 / 调试窗口）。
  2. `Views/EngineerPage.xaml` 选择工位 ComboBox —— 改用 `ItemTemplate = DataTemplate { TextBlock Text={Binding Name, FallbackValue=未命名工位} }`。直接 ItemTemplate 路径不依赖 DisplayMemberPath，绑不到 Name 时用 FallbackValue 兜底。
- 验证：`dotnet build` → **0 error / 24 warning（历史 baseline）**。

### 3. 一个被加固的 WPF 经验
- ComboBox 用 `DisplayMemberPath` 在多种样式（`CellComboStyle` `AppleCombo` `AppleComboReadOnly`）下都可能因回退路径显示类型名。**最小成本的兜底是给数据模型 `override ToString()` 返回 Name**，所有 binding 失败路径立刻恢复为可读文字，对 UI / 日志 / 调试都有用。
