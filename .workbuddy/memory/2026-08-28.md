## 「点表格不显示表格页」根因（FlowPage 被视觉页加载异常拖垮）
- 用户报：点左侧表格流程项，右侧表格编辑区不显示（与之前「视觉不切换」是同一现象，整页右侧都白）。
- 机制核对（全部 OK，排除机制层）：
  - `FlowViewModel.IsKindTable/Lua/Vision` 是 `SelectedItem?.Kind == ...` 计算属性；
  - `ListEditorViewModel<T>.SelectedItem` setter 走 `SetField` → 带出 `OnPropertyChanged("SelectedItem")`；`FlowViewModel` 的 `OnPropertyChanged(SelectedItem)` override 显式发 `IsKindTable/Lua/Vision` 三个通知 → 表格区域 `Visibility=IsKindTable` 会刷新；

## MC3093 + XamlParseException 修复（FlowPage 视觉宿主：ContentControl + 不可命名 + 用 Content 绑）
- 用户报两次：先 `ContentControl x:Name=VisionHost` 报 MC3093；改 `Border x:Name=VisionHost` 后**仍报 MC3093**（"Border"在元素"EditorPage"的范围内，在另一范围内定义它时，已注册了名称）。
- ⚠️ **关键更正（之前记错过）**：之前以为"Border 不创建 NameScope，命名安全"——**错误**。MC3093 与元素类型无关（ContentControl / Border 都会触发）。真正规则：**凡在 `EditorPage.Detail`（ContentControl）内容里放 `x:Name` 的元素，名字会同时注册到「EditorPage 作用域」与「ContentControl 内容作用域」两个 NameScope → 必然 MC3093**。（表格 Grid / LuaEditorView 不报，正因它们没用 x:Name。）
- 最终修法（已落盘，正确版）：
  - `Views/FlowPage.xaml`：宿主改为 `<ContentControl>`（**无 x:Name**），`Content` 绑 `VisionContent`（`RelativeSource AncestorType=local:FlowPage`），`Visibility` 仍绑 `IsKindVision`。无命名元素 → 无 MC3093；用 Content DP（而非 Border.Child CLR）→ 绑定合法。
  - `Views/FlowPage.xaml.cs`：在 `FlowPage` 上加依赖属性 `VisionContent`（`DependencyProperty.Register(nameof(VisionContent), typeof(UIElement), typeof(FlowPage), null)` + CLR 包装）；`EnsureVision()` 不再碰任何命名控件，而是 `VisionContent = new VisualFlowPage()`（catch 时赋橙色 TextBlock）。延迟/异常兜底逻辑不变。
- ⚠️ **必须整体 Rebuild（Ctrl+Alt+F7），不能增量 Build**：旧 `obj/.../Views/FlowPage.g.cs` 仍含 `Border VisionHost` 字段与强转；增量 Build 会沿用该 stale 文件。Rebuild 重生成后该字段消失，且新 .g.cs 不再引用 VisionHost，MC3093 / "does not contain a definition" 都消失。XDG000/XDG-00 是设计期幽灵，以 Output "Build succeeded" 为准。
- 附带确认的结构：FlowPage 编辑器区三层（`Grid Visibility=IsKindTable` / `LuaEditorView Visibility=IsKindLua` / `ContentControl Visibility=IsKindVision` 且 Content 绑 VisionContent）是 `Grid Grid.Row=1` 内的兄弟节点，互斥可见，互不影响；表格区域结构完整。
- 经验沉淀（**WPF 通用**，与项目无关）：
  1. **任何 ContentControl 直接内容里给子元素命名 = 必踩 MC3093**；要用命名引用就走「依赖属性 + RelativeSource/ElementName 绑定」，或视觉树查找（按 Tag），不要 x:Name。
  2. **承载+绑定的单子元素用 ContentControl**（`Content` 是 DP、可绑），别用 Border（`Child` 是 Decorator 的 CLR 属性、不可绑——XAML 上写 `Child="{Binding...}"` 会立即抛 XamlParseException）。想自定义外观把 `ContentControl.Template` 设成带圆角/背景/边框的 ControlTemplate 即可。
