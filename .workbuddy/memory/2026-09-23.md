### 控制器页面「根据底层重新写一个」——在线状态去 UI 影子字典（同日，最新）
- 用户指令：「控制器页面根据底层重新写一个」——在线/连接状态要**真实反映底层硬件反馈**，而不是 UI 自己维护一份影子状态。
- 根因（旧实现）：`AxisControllerViewModel` 用运行期 `Dictionary<AxisControllerItem,bool> _online` 自记在线态，UI 与底层 `SamsunCardBridge` 的 `_slots` 真相可能不同步（连接失败/外部断开后 UI 仍显在线）。
- 改法（VM 只读底层）：
  ```csharp
  public bool IsOnline {
      get {
          var ctl = SelectedItem; if (ctl == null) return false;
          if (HardwareSetup.Mode == HardwareMode.CardFamilies && HardwareSetup.CardFamilies != null)
              return HardwareSetup.CardFamilies.IsControllerReady(ctl.Name);   // ← 底层真相
          if (HardwareSetup.Mode == HardwareMode.Leadshine) return HardwareSetup.IsCardReady;
          return false;
      }
  }
  public string ConnectionText => IsOnline ? "在线" : "离线";
  public IReadOnlyList<string> ConnectionStatusLines => HardwareSetup.CardFamilies?.ControllerStatus() ?? Array.Empty<string>();
  ```
  **删除** `_online` 字典与 `SetOnline(ctl,bool)`；`FetchModules()/Connect()/Disconnect()` 末尾改调 `RaiseConnection()`+`RaiseStatusLines()`（后者 = `OnPropertyChanged(nameof(ConnectionStatusLines))`）。
- `Views/AxisControllerPage.xaml` 整页重写：基本信息 / 扩展IO模块 / 连接状态 / 数量汇总 全保留，新增「**底层连接总览（真实状态）**」`AppleGroupCard`——`ItemsControl` 绑 `ConnectionStatusLines`（逐行 = `ControllerStatus()` 的「名称：状态」），空列表时 DataTrigger 切 `ControlTemplate` 显示「暂无已连接的控制器」。仅用 `AppStyles.xaml` 现有键（SubLabel/MiniNumBox 本地补），下拉无 IsEditable。
- 教训（已入 MEMORY.md）：**任何在线/就绪类 UI 状态一律读底层 API（`SamsunCardBridge.IsControllerReady` / `ControllerStatus()` / `HardwareSetup.IsCardReady`），禁止在 VM 里自建在线影子字典**。
- 构建 0 错误。
