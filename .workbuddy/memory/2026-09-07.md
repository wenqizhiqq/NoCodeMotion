### 修复 运算 列空白
- 截图显示 运算 列所有行只有下拉箭头、无文字。根因：`OperationOptions`（`Views/FlowPage.xaml`）只含 `修改为` / `等于`，而 `ProjectTemplateCatalog` 各助手实际写入 `Operation = "修改"` / `"是否等于"`，下拉 `SelectedItem` 找不到匹配项 → 显示为空。
- 在 `OperationOptions` 追加：`修改`、`是否等于`、`是否不等于`、`是否大于`、`是否小于`、`是否大于等于`、`是否小于等于`（保持原有 加/减/乘/除/取模/取反/与/或），覆盖模板与运行时常用值。

### 教训
- WPF ComboBox `SelectedItem` 绑定：当数据值不在 `ItemsSource` 中时静默显示空白（不报错），运行时视觉上是「下拉箭头 + 空内容」，最坑。修复一律先把 `ItemsSource` 写齐或 `IsEditable` + `Text` 绑定。
- 删 XAML 列 ≠ 删模型属性。要彻底剥离某个特性得把 `FlowStep.TimingMark/SyncGroup` + 持久化层 + 引用方都一起删；本次仅 UI 删列、保留模型以兼容老工程文件。
