## 错误详情弹窗过大 + IndexOutOfRange 根因
- **错误弹窗太大、空白多**：`Views/ExceptionDetailDialog.xaml` 的 `<Window>` 缺 `SizeToContent`，默认按窗口 natural size 显示（~960×680），即便内容只有一行也撑满。修复：Window 加 `SizeToContent="WidthAndHeight"`，自动收缩到 StackPanel 的 MinWidth/MaxWidth + TextBox MaxHeight+ 按钮区。`AllowsTransparency=True` + 透明背景让"未填充区域"看起来全是空白。
- **IndexOutOfRange 根因**：`Models/TrayItem.cs` 的 `Rows`/`Cols` setter 用 `SetField(ref, value)` → `SetField` 内部立即 `OnPropertyChanged(propertyName)` → `TrayPage.OnItemChanged` 立刻触发 `RenderTray()`，但此时 `_rows/_cols` 已更新、`Cells` 还是旧的 → RenderTray 用新 Rows/Cols 索引旧 Cells（Count=旧 Rows*Cols），如 5×5→10×5 时 `Cells[r*5+c]` 在 r=5 即越界。
- **修复**：Rows/Cols setter 改成「先赋值 → 调 RegenerateCells() 重建 Cells → 再 OnPropertyChanged()」，保证 RenderTray 看到的 Rows/Cols/Cells 三者始终一致。Cells 集合在 RegenerateCells 内部重建时会再触发一次 OnPropertyChanged(nameof(Cells))，RenderTray 重绘时 Cells.Count 已正确，多画一次帧但不出错。

## 轨迹仿真面板布局修正（用户反馈：不需要折叠按钮 + 图标显示不全）

- **修复**：
  - 删掉标题栏的折叠 `Button`（`SimTogglePanelCommand` + `DownIcon`）及可折叠 `<StackPanel Visibility=...>` 包裹，面板改为「标题 + 控制条 + 画布/速度/读数」始终全部可见。
  - 4 个控制按钮（SimPlay/SimStop/SimReset/SimLoop）全部加 `MinWidth="0"`，强制宽度落到 34px，4×34 + 间距 ≤ 252 面板内宽，图标全显示。
  - `ViewModels/PointViewModel.cs` 删除孤立的 `SimPanelExpanded` 属性与 `SimTogglePanelCommand` 命令（折叠功能已撤销）。
- **验证**：`dotnet build -c Debug`（PowerShell 通道）0 错误 0 警告（已成功生成）。

## 工程师页「轴控制 ↔ 点位表」解耦（用户反馈：点位表的轴是固定的）
- **根因**：`Views/EngineerPage.xaml` 右下角「点位移动和设置」的 4 个轴列头（`H0Pos`...`H3Spd`）模板里所有 `Binding` 写的是 `DataContext.AxisStates[i].AxisName`，而 `DataContext = EngineerViewModel`；同一 `AxisStates` 又绑给左上的「轴控制」卡片下拉框。结果：**用户改左上「选择轴」下拉框，会同时改动顶部卡片标签 + 底部点位表列头**。
- **修复**：把点位表列头的轴名数据源与调试面板的轴槽解耦：
  - `ViewModels/EngineerViewModel.cs` 新增独立集合 `ObservableCollection<EngineerAxisState> PointAxisStates`（4 槽，仅服务于点位表列头）。订阅 `PropertyChanged(nameof(SelectedTable))` 与当前工位 `PointTable.PropertyChanged(nameof(AxisNames))`；`LoadPointAxisNames()` 把 `SelectedTable.AxisNames[i]` 同步到 `PointAxisStates[i].AxisName`，切换工位 / 其它入口（如 PointPage）改了工位轴名时列头即时刷新。
  - `Views/EngineerPage.xaml` 8 个 `H0Pos`..`H3Spd` 模板的所有 `DataContext.AxisStates[i].AxisName` 改绑 `DataContext.PointAxisStates[i].AxisName`，列头不再跟随左上调试下拉框。
  - `AxisStates` 仍为调试面板的瞬时控制对象（不落盘、不联动工位）；`MoveToPoint/SaveCurrent` 等命令继续读写 `AxisStates[i].CurrentPosition`，因为它们本质上是「调试这 4 个轴槽」，与点位表列头含义不同。
- **验证**：`dotnet build -c Debug`（PowerShell 通道）0 错误，仅遗留 FlowRunnerService/OperatorViewModel/VisionEngine 的可空性警告。
