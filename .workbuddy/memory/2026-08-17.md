# 2026-08-17

## NoCodeMotion — WPF 无代码运动控制软件（初始骨架）

搭建了 .NET 10 WPF 项目（D:\wqz\code\NoCodeMotion），实现用户需求：顶部导航栏（轴/IO/气缸/通讯/料盘/流程），每个页面左侧项目列表 + 顶部添加/删除按钮。

复用架构：
- `Views/EditorPage.xaml`：通用编辑页框架（上工具栏 添加/删除 + 左 ListBox + 右详情 ContentControl）。`Detail` 为依赖属性，各页面注入表单。
- `ViewModels/ListEditorViewModel<T>`：泛型基类，封装 Items / SelectedItem / AddCommand / DeleteCommand，子类只需实现 CreateNewItem()。
- `Models/EditorItemBase`：项目基类（Name）。
- 6 个页面 VM/View：Axis/Io/Cylinder/Comm/Tray/Flow，各含领域字段（轴含类型/回零/速度，气缸含输出点/感应，通讯含串口/TCP 等）。
- `MainWindow`：导航栏切换页面，并缓存页面实例以保留各自数据。

构建：`dotnet build` 通过，0 警告 0 错误。

## 流程页改为步骤表格
- 新增 `Models/FlowStep.cs`（逻辑/功能/名称/运算/设置值/耗时ms 六字段）。
- `FlowItem` 改为持有 `ObservableCollection<FlowStep> Steps`。
- `FlowViewModel` 增加 `SelectedStep` 及 `AddStepCommand`/`DeleteStepCommand`（步骤增删，需在选中某流程时可用）。
- `Views/FlowPage.xaml`：右侧改为 `DataGrid`（逻辑/功能 用 ComboBox 列，含选项数组资源），上方「添加步骤/删除步骤」工具栏；顶部通用 添加/删除 仍管理左侧“流程”列表。

## 流程名称列改为下拉 + 下拉框单击即展开
- 新增 `Services/Catalog.cs`：全局对象目录（AxisNames/IoNames/CylinderNames/CommNames/AllNames），各页面把已配置名称同步进来。
- `ListEditorViewModel<T>` 增加 `CatalogCategory`（子类构造函数设为 Axis/Io/Cylinder/Comm），Add/Delete 及名称变更时同步到 Catalog；流程/Tray 页不设置（不贡献名称）。
- `FlowPage` 的「名称」列改为 `DataGridComboBoxColumn`，ItemsSource 绑定 `Catalog.AllNames`（轴/IO/气缸/modbus 的已配置名称）。
- 单击即展开下拉：通过 `PreparingCellForEdit` 设 `IsDropDownOpen=true` + `MouseLeftButtonDown` 调 `BeginEdit()`（DataGrid 用 sender 引用，因放在 EditorPage.ContentControl 内不能用 x:Name，否则 MC3093 报错）。

## 引入 HandyControl 库
- `dotnet add package HandyControl` 3.5.1（兼容 net10）。
- `App.xaml` 合并 `pack://application:,,,/HandyControl;Component/Themes/SkinDefault.xaml`，全局套用 HC 默认样式（ComboBox/DataGrid/TextBox 等），自定义 keyed 样式不受影响。
- 流程「名称」列用 `Views/FunctionToNamesConverter.cs`：按“功能”列映射到对应名称库（轴→AxisNames，IO→IoNames，气缸→CylinderNames，modbus→CommNames），实现“按其他页的库筛选”。
- 流程页 4 个下拉列（逻辑/功能/名称/运算）从 `DataGridComboBoxColumn` 改为 `DataGridTemplateColumn`，编辑模板内显式使用 `hc:ComboBox`；`PreparingCellForEdit` 改为在编辑元素内查找 `ComboBox` 并打开下拉。

## 自动保存 / 自动载入
- 新增 `Models/ProjectData.cs`：聚合所有页列表，作为单一真实来源。
- 新增 `Services/ProjectStore.cs`：JSON 读写，文件位于 `%LocalAppData%\NoCodeMotion\project.json`；防抖保存（Timer 400ms）；`Load()` 在 `App()` 构造里调用，`OnExit` 强存。
- 各页 VM 的 `Items` 改为引用 `ProjectStore.Data` 的共享集合（构造里赋值 + `Counter=Items.Count` + `AttachAutoSave()`）；`AttachAutoSave` 订阅 CollectionChanged/属性变更触发 `ScheduleSave()`，并同步 Catalog。
- `FlowViewModel` 额外订阅每个 FlowItem.Steps 的增删及步骤属性变更以保存。
- `App.xaml.cs`：`public App(){ ProjectStore.Load(); }` + `OnExit` 调 `Save()`。

## 下拉单击修复
- 之前仍要 2 次点击：根因是 BeginEdit 编辑的是“旧当前单元格”。改为在 `PreviewMouseLeftButtonDown` 里先 `grid.CurrentCell = new DataGridCellInfo(点击的 cell)` 再 `BeginEdit()`。
- `PreparingCellForEdit` 用 `Dispatcher.BeginInvoke(Render 优先级)` 延迟打开 `IsDropDownOpen`，避免被同一次鼠标抬起误判为外部点击而关闭。
