# 2026-10-12 NoCodeMotion 工作日志

## 运控 2D 仿真（Sim2DView，第一版落地）

需求：用户要「运控 2D 仿真」，问怎样做好 → 方案定为：与 3D 仿真并列挂在操作员页右列，2D/3D 药丸切换（默认 2D），数据源与 3D 完全一致（AxisRuntimeState + SimRuntime），不加任何新接口。

### 新增文件
- `Services/Sim2DMotion.cs`：2D 运动学内核（纯 C# 无 UI）。以 AxisRuntimeState 为唯一指令位置源（SimFlowPlayer 低通插值写入 → 追踪；Stub/点位瞬时写入 → 梯形规划滑向目标）；单轴梯形速度规划（Speed×倍率、Accel/Decel 时间取 AxisItem），刹停约束 v≤√(2a·|dist|) 无过冲；软限位钳制；按住点动由内核持续前推目标并回写共享态；XY 轨迹采样（容量 4000）。
- `Views/Sim2DView.xaml/.cs`：俯视画布（网格+软限位框+X导轨+Y横梁+刀头，刀头内芯大小=Z 行程百分比）+ 实时位置/目标/速度读数 + 十字点动键（JogHoldBehavior 按住连动，X±/Y±/Z±）+ 回零/停止 + 倍率 Slider(1~100%，默认 10%) + 轨迹显隐/清空 + 底部 IO输出/气缸/相机 状态药丸（250ms 刷 SimRuntime）。轴映射：名称含 X/Y/Z 优先 → 顺序补位 → 虚拟轴兜底；无轴配置给虚拟 X/Y/Z。DispatcherTimer 16ms 推进+直接改 Canvas 几何（无绑定开销），仅 IsVisible 时计时。
- `Views/OperatorPage.xaml`：右列改「运行仿真」，加 2D/3D RadioButton（SimToggleBtn 样式，默认 2D），Sim2DView/Sim3DHost 同 Grid 叠放切 Visibility；`OperatorPage.xaml.cs` 加 `SimMode_Changed`（解析期判空跳过，初始可见性由 XAML 定）。
