### 实现要点
- 新增 `Services/Cad/DwgReader.cs`（Aspose.CAD 26.7.0 读取二进制 DWG / DXF 文本，二者都返回 `CadImage`）：
  - 递归展开 `CadInsertObject` → `CadBlockEntity`（`img.BlockEntities[name]`，带深度 ≤24 与访问集合防环）。
  - 提取线段：`CadLine` FirstPoint→SecondPoint；`CadLwPolyline` Coordinates（闭合 flag 接首尾）；`CadCircle`/`CadArc` 按半径采样成段（注意 **CadArc 继承自 CadCircle，switch 必须 Arc 在 Circle 之前**）；`CadArc` 顺时针用 `CounterClockwize!=0` 判定。
  - 提取文字：`CadText`(FirstAlignment/DefaultValue/TextHeight/TextRotation)、`CadMText`(InsertionPoint/Text/InitialTextHeight/RotationAngleRad)。
  - **不调用 `Image.Save` 栅格化** → 无 Aspose "Evaluation only" 水印（仅栅格导出才有）。
  - 聚类取景：`ComputeFitBounds` 网格连通分量聚类，选面积最大的图块作为相机取景目标。本文件实测 96% 图元在 Y≈-2.5M（电缆表/明细，被拖到远处），主图块为机器立面 X∈[-3,860] Y∈[2797,24596]（863×21799），正确剔除离群块。
- `Sim3DView` 集成：新增字段 `_dwgContent/_dwgCenter/_dwgRadius`；`BuildScene` 的 `_cadMode` 分支同时支持 DWG 与 STP（DWG 优先）；`BtnImportDwg_Click` + `LoadDwgFile`（Task.Run 后台读 + Dispatcher 装配）；`BuildDwgModel`（线段烘焙成 XZ 平面细矩形网格 + 半透明背板 + `Viewport2DVisual3D` 文字标签，按取景包围盒居中缩放，target=180 场景单位，剔除离群段）；`MakeDwgLabel`；XAML 工具栏加「导入DWG/DXF」按钮（紧邻「打开STP」）；`BtnClearStp` 同时清除 DWG。
- `NoCodeMotion.csproj` 加 `<PackageReference Include="Aspose.CAD" Version="26.7.0" />`。

### 构建坑（重要，可复用）
- 本机 .NET 10 SDK(10.0.102) WPF 临时工程 `_wpftmp` 会 **CS0579 重复特性**（同时含主工程生成的 `NoCodeMotion.AssemblyInfo.cs` 与自带 `_wpftmp.AssemblyInfo.cs` / `.NETCoreApp,Version=v10.0.AssemblyAttributes.cs`）。
  - 修复：csproj 加 `<GenerateAssemblyInfo>false</GenerateAssemblyInfo>` + `<GenerateTargetFrameworkAttribute>false</GenerateTargetFrameworkAttribute>`；共享的 `[assembly:ThemeInfo(...)]` 留在根 `AssemblyInfo.cs`（仅此一项、不冲突）。
- Bash 工具对 dotnet 一律 LOLBin 拦截（含 `run_in_background` 包装也触发）；**用 PowerShell + 绝对路径 `C:\Program Files\dotnet\dotnet.exe` 前台构建** 是唯一稳定通道。
- `DiffuseMaterial` 无 `Opacity` 属性 → 透明度要设在 `SolidColorBrush` 上。
