## net8 降级尝试（已还原）
- 应用户要求尝试把 NoCodeMotion.csproj 从 net10.0-windows10.0.19041.0 降到 net8.0-windows10.0.19041.0 并推送，最终用户决定放弃，保留 net10，全部还原。
- 关键结论：
  - `OcctNet.Wrapper` 0.1.1（NuGet）仅有 lib/net10.0 目标，net8 还原即报 NU1202；本机 SDK 只有 9.0.317 / 10.0.102，无 8.x SDK。
  - 尝试绕过：直接 `<Reference>` 引用 net10 编译的托管 DLL → 编译期 CS1705（System.Runtime 10.0 > 8.0），不可行。
  - 尝试运行时反射加载（AssemblyLoadContext.LoadFromAssemblyPath + dynamic）：托管程序集能在 net8 运行时加载成功，但首次调用 OcctShape.ImportStep 后 test.exe 挂死（未验证到 OCCT 原生库加载结果）。net10 仍是该包唯一可行目标。
- 操作记录：
  - csproj 已 git checkout 还原到 net10（工作区 clean，HEAD=f6e1294 与 origin/master 一致）。
  - 临时工程 `.occt_test/` 已删除；期间发现测试进程 test.exe(PID 54924) 残留锁住 bin 下 test.dll 导致目录删不掉，kill 后正常删除。
