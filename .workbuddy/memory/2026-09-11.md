# 2026-09-11 工作记录

## 全局苹果 iOS 风格化（颜色/样式/图标/字体）

- 目标：用户要求「整个界面所有东西都改成苹果 iOS 风格颜色样式图标」。原 `Resources/AppStyles.xaml` 已是 iOS 调色板（#007AFF 等），但**缺隐式全局控件样式**——未显式指定 Style 的 Button/CheckBox/Slider/ScrollBar/ContextMenu/Tab/GroupBox 等仍走 Windows 默认外观，所以大量界面不是 iOS。
- 改动（`Resources/AppStyles.xaml` 末尾新增「隐式全局 iOS 控件样式」段，均不带 x:Key，自动作用于所有未指定 Style 的控件；已命名样式 TtBaseBtn/CellComboStyle/Apple* 不受影响）：
  - `Button`→BasedOn `TtBaseBtn`（蓝填充圆角，iOS 主操作）
  - `CheckBox`→iOS 开关（绿底+滑块，内容右移 54）
  - `RadioButton`→圆环+实心点
  - `Slider`→细线轨道+圆形滑块（标准 Track 结构，Decrease/Increase RepeatButton + Thumb）
  - `ScrollBar`/`ScrollViewer`→iOS 细滚动条（复用 `iOSScrollBar`）
  - `ContextMenu`/`MenuItem`/`TabControl`/`TabItem`/`ProgressBar`/`GroupBox`(卡片+内嵌标题)/`Separator`(发丝线)/`Window`(全局字体) 隐式 iOS
  - **故意不做**隐式 `TextBox`/`ComboBox`/`ToggleButton`：`CellComboStyle` 内部 ToggleButton/TextBox 模板会被隐式样式破坏（会导致下拉箭头、选中文字、可编辑框丢失）。
- 图标：原图标是 Material 实心 Geometry。用 Python 脚本把全部 `Data={StaticResource *Icon/*Geometry}` 的 `<Path>` 由 `Fill` 改为 `Stroke`（SF Symbols 描边风），加 `StrokeThickness="1.6"` + `Fill="Transparent"`；跳过带 `Style=` 的（如 `PageHeaderIcon` 已单独改为 Stroke）。**27 个 XAML 文件**被转换（MainWindow 导航、各 Page/Dialog）。`PageHeaderIcon` 样式本身 Fill→Stroke 改写。
- 字体：`MainWindow` 与隐式 `Window` 样式设 `FontFamily="SF Pro Display, SF Pro Text, PingFang SC, Microsoft YaHei, Segoe UI, sans-serif"`（Windows 无 SF Pro 时回退雅黑/Segoe，macOS 用 PingFang）。
- 构建：`dotnet build -c Debug` **0 错误**（92 警告均为 CA1416 平台兼容，非错误）。XAML 经 BAML 编译通过即证明标记合法。
- 说明：沙箱无显示器，无法实拍 UI；视觉正确性需用户运行 `NoCodeMotion.exe` 验收。导航图标保持 multicolor 描边（类似 iOS 多彩 SF Symbols）。个别页面若仍有内联非 iOS 布局，可后续按同一命名样式替换。
