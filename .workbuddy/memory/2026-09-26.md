# 2026-09-26

## 流程「轴」步骤运算列缺少移动命令（已修）
- 问题：流程页「运算」列对所有功能共用一份 OperationOptions（修改/修改为/加/减…），轴步骤看不到「移动」类命令；且旧「修改/修改为」在 ExecAxis 里被当成绝对移动，用户困惑「轴位置修改为0 为什么不移动」。
- 改动：
  - 新增 `Views/FunctionToOperationsConverter.cs`（IValueConverter）：功能=轴 → 运算下拉显示「绝对移动 / 相对移动 / 回零 / 停止」；其它功能 → 通用运算。
  - `Views/FlowPage.xaml` 运算列 ComboBox 的 ItemsSource 改为 `{Binding Function, Converter={StaticResource FunctionToOperationsConverter}}`，并注册转换器。
  - `ViewModels/FlowRunnerService.cs` 的 `ExecAxis` 重写：按运算词精确分发（绝对移动→MoveAxisAbs；相对移动→MoveAxisRel；回零/停止；"修改/修改为"作向后兼容仍走绝对移动）；属性=速度 时把设置值当速度下发（修掉旧版把属性名当数值解析、永远不调速的 bug）；回零/停止不再要求解析设置值。
- 说明：未加「设零」命令——IHardwareBridge 接口未声明 SetAxisZero（加密实现层会编译失败），如需清零命令后续再扩接口。
- 构建：PowerShell + 绝对 dotnet 构建到 C:\tmp\nocode_out\，EXIT=0，0 错误。
- 用户注意：流程运行走 FlowRunnerService（OperatorViewModel 的 RunAll），加密的 FlowViewModel 单步路径未改；bin 被运行中的 exe 锁定，需先关闭再正常构建或用临时产物验证。

## 流程「实际值」列改为显示真实内容并 1 秒刷新（已修）
- 问题：流程页「实际值」列只显示一个圆点，没有文字内容；旧 `RefreshActualValues()` 仅对 `Function=="变量"` 回填变量值，其它功能（轴/IO/气缸/相机）的 ActualValue 始终为空，导致表格看起来只有蓝点。
- 改动：`ViewModels/FlowViewModel.cs` 的 `RefreshActualValues()` 扩展为按「功能 + 属性」读取真实状态：
  - 变量 → 当前变量值（原逻辑保留）。
  - 轴·位置/编码器位置 → `AxisRuntimeState.Get` 当前位置（格式化 0.###）。
  - 轴·速度 → 轴配置速度；轴·使能 → 已使能/未使能。
  - IO·输出状态 → `SimRuntime.GetOutput`；IO·输入状态 → `HardwareBridge.Current.ReadInput`。
  - 气缸 → 伸出/缩回。
  - 相机 → 已连接/未连接。
  - 定时器仍为构造时启动的 1 秒 DispatcherTimer；单步读取异常只清空该步，不影响其它。
- 说明：圆点仍保留作为状态/当前行指示器；内容填充后，圆点左侧 + 文字右侧同时显示。若 AxisRuntimeState 没有该轴的位置（如实机运行未回写），位置显示为 0；后续如需把真实卡位置回写 AxisRuntimeState，应在桥接层统一处理。
- 构建：PowerShell + 绝对 dotnet 构建到 C:\tmp\nocode_out\，EXIT=0，0 错误（608 个既有警告）。
