## 设零点失败（卡返回 20480）排查
- 报错只可能来自 `WenQiZhiCardBridge.SetAxisZero`（雷赛桥的文案不同）→ 说明当时处于**卡族模式**。
- 找到真 bug：`CardFamilyCatalog.Resolve` 第③步「只给品牌+总线」时，脉冲分支原来取「第一个声明支持 Pulse 的卡族」= **DMC_E3032_EtherCAT（总线主站）**，于是雷赛 DMC5400（PCI 脉冲，见 工程13/9.xlsx / _DefaultProject）被匹配到总线族，设零点走了 `dmc_set_position_unit`（单位/总线 API）→ 卡返回非 0。
  修复：脉冲分支优先取「含 Pulse 且**不含 EtherCAT**」的纯脉冲族（雷赛 → DMC3400A），总线分支保持原有「纯总线」优先。
- `SetAxisZero` 失败文案改为带 **卡号 / 轴号 / 卡族 Key / 原始返回码** + 提示（总线轴先使能、确认伺服就绪与脉冲当量）。
- 构建 0 错误（nocode_int34/35、out34/35）。
