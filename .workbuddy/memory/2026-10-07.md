## ★ 自定义页面（可视化设计器）第一版
需求原话：「工程师按钮右侧添加一个自定义按钮，页面内部 也就是用户可以从左侧工具箱拖拽控件：按钮，输入框这些到中间工作区，拖动位置和大小，右侧属性页面设置参数，修改或者显示IO，气缸，变量，轴参数，轴移动这些」。

### 结构（新增 3 个文件 + 6 处接线）
- `Models/DesignerWidget.cs`：控件模型（继承 EditorItemBase，INPC）——
  `WidgetType`(按钮/输入框/显示框)、`X/Y/Width/Height`、`Text`、`Action`(动作/显示内容)、`Target`(目标名)、`Param`(参数)。
  X/Y 的 setter 内含 `value<0→0`，Width/Height 有下限 40/24（拖动越界自动钳制）。
- `ViewModels/CustomDesignerViewModel.cs`：
  - `DesignerWidgetVM`：包装 Model + `LiveText`(显示框运行时文本，不落盘) + `IsSelected`(画布高亮)。
  - `Widgets` 与 `ProjectStore.Data.DesignerWidgets` 同步维护（AddWidget/DeleteSelected/ClearAll 同时动两边）。
  - `ActionOptions`（按类型：按钮 8 种 / 输入框 2 种 / 显示框 6 种）、`TargetOptions`（按动作给 IO 名/气缸名/变量名/轴名候选，ComboBox IsEditable 可手输）。
  - `Execute()`：按钮动作真实下发——写输出IO（开/关/切换，切换先 `ReadOutput` 读回再取反）、气缸（伸出/缩回/切换，`CylinderMove`+`SimRuntime.SetCylinder`+`CurrentState`）、轴移动绝对/相对（`MoveAxisAbs/Rel`）、轴回原、轴停止、写变量（`SimRuntime.SetVariable`）；找不到目标/参数非数字 → 状态栏红字，不抛。
  - `CommitInput()`：输入框回车/失焦 → 写变量。
  - `RefreshLive()`：显示框 250ms 读回——显示IO（输出走 `ReadOutput`、输入走 `ReadInput`）、显示气缸（优先读 SensorExtend/SensorRetract 真实输入，没有则 `SimRuntime.GetCylinder`）、显示变量（`GetVariableResolved` 支持表达式）、显示轴位置（`ReadAxisPosition`）、显示轴参数（Param=速度/加速时间/减速时间/点动距离/手动速度）。
- `Views/CustomDesignerPage.xaml` + `.xaml.cs`：三栏布局（工具箱170 / 画布* / 属性260）。
  - **设计/运行模式**（RadioButton 胶囊组）：设计模式控件 `IsHitTestVisible=false`（点击穿透到 Grid → 拖动），运行模式按钮可点、输入框可输。
  - **拖拽**：工具箱 `MouseMove+左键` → `DoDragDrop("designer-widget-type")` → Canvas `Drop` 按鼠标点居中放置。
  - **拖动**：控件 Grid `MouseLeftButtonDown`（选中+捕获鼠标）→ `MouseMove` 更新 Model.X/Y → `Canvas.Left/Top` 绑定自动跟。**ButtonBase 会吞掉 MouseLeftButtonDown**，所以运行模式点按钮=执行、设计模式 IsHitTestVisible=false 才能拖 —— 两个模式天然不冲突。
  - **缩放**：右下角 10px Ellipse 手柄（仅选中时显示），同样捕获鼠标改 Width/Height。
  - **Delete 删除**：页面 `PreviewKeyDown`，`Keyboard.FocusedElement is TextBox` 时跳过（别拦输入）。
  - 定时器 250ms：Loaded 启动 / Unloaded 停止（页面被 MainWindow 缓存，不关就是常驻）。
- 接线：`MainWindow.xaml`「工程师」右侧加 Tag="Custom" 按钮（CustomIcon 网格图标、#5856D6）；
  `MainWindow.xaml.cs` `_pages["Custom"]` + `"Custom" => "自定义"`；`AppStyles.xaml` 加 CustomIcon + NavIconCustomBrush。
- **持久化**：`ProjectData.DesignerWidgets`（根 public 集合，XlsxProjectStore 反射自动落盘）+ `CopyFrom` 补一行 +
  `SheetNameOverrides["DesignerWidgets"]="自定义"` + MenuSheetNames 插在「工程师」后。零 xlsx 专用代码。

## 运行模式精简界面
- 需求：运行模式不显示工具箱、右侧属性面板、「删除所选」「清空画布」按钮。
- 实现（纯 XAML，只动 `CustomDesignerPage.xaml` + 加一个转换器）：
  - `CustomDesignerPage.xaml.cs` 新增 `BoolToColWidthConverter`：true→参数像素 GridLength，false→`GridLength(0)`。
  - 三列列宽绑定 `IsDesign`（`ElementName=PageRoot`——**ColumnDefinition 不在可视树、吃不到 DataContext，必须显式 ElementName**），运行模式两列收成 0，画布自动占满。
  - 工具箱/属性 DockPanel + 两个按钮 `Visibility={Binding IsDesign, Converter=BoolToVis}`。
- nocode_int42/out42：0 错误；冒烟 25s 存活、标题正常、0 错误事件。

## 属性面板「参数」按动作切换下拉/输入框
- 需求：根据动作显示下拉框或输入框（截图=参数还是裸 TextBox）。
- 实现：
  - VM 加 `ParamOptions`（`IReadOnlyList<string>?`）：写输出IO→开/关/切换；气缸→伸出/缩回/切换；显示轴参数→AxisParamNames；其它动作 null=自由输入。
  - `SelectedWidget` setter 订阅/退订 `Model.PropertyChanged`，`Action` 变化时刷新 ParamOptions + TargetOptions，并把不合候选的旧参数收敛成默认值（`m.Param = opts[0]`，如切到「写输出IO」空参数自动填「开」）。
  - XAML 参数行 ComboBox（绑 ParamOptions，非 IsEditable）+ TextBox（`NullToVisConverter` 参数 "inv"）二选一；新转换器 null→Collapsed / "inv" 反转。
- ⚠ 踩坑：一次 Edit 的 old_string 带尾换行、new_string 不带，把 `///</summary>` 注释和下一行属性声明并成一行 → `TargetOptions` 声明被注释吞掉，报 119 个 CS1519。修法=把声明拆回独立行。
- nocode_int44/out44：0 错误；冒烟 25s 存活、0 错误事件。

## 修 UI 异常：只读属性 IsRunMode 被 TwoWay 绑定
- 现场报「无法对 CustomDesignerViewModel.IsRunMode 进行 TwoWay 或 OneWayToSource 绑定」——「运行模式」RadioButton 的 IsChecked 默认 TwoWay，而 IsRunMode 是只读计算属性（`!IsDesign`）。
- 修复：`IsChecked="{Binding IsRunMode, Mode=OneWay}"`。同组互斥靠「设计模式」的 TwoWay 绑定驱动即可。
- nocode_int45/out45：0 错误；冒烟 10s 存活标题正常（事件日志里 08:44:17 那条是 VS WpfTap 环境噪音，无关）。
