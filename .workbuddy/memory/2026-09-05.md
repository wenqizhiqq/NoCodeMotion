## BepuPhysics v2 关键 API 踩坑（headless 验证时发现，真会导致运行时崩溃/NaN/不联动）

1. **`new SolveDescription()` 非法**：结构体默认全 0 → `SubstepCount=0` → `Simulation.Create` 抛 "Substep count must be positive"。必须用 `new SolveDescription(velocityIterationCount:1, substepCount:1)` 即 `new SolveDescription(1,1)`。
2. **`PairMaterialProperties` 默认 `SpringSettings` 致 NaN**：`new PairMaterialProperties()` 的 `SpringSettings` 默认频率 0/阻尼 0，物体一接触求解器除零→位姿 NaN。必须在 `ConfigureContactManifold<TManifold>` 内显式 `pairMaterial.SpringSettings = new SpringSettings(30f,1f);`（需 `using BepuPhysics.Constraints;`）。
3. **运动学↔动态切换不能靠 `BodyReference.LocalInertia = x`**：`LocalInertia` 是 ref 返回属性，赋值只写回惯性结构体、**不会**更新 `Collidable.Mobility`，导致运动学→动态切不回去（拖拽松手工件不落）。正确：运动学用 `br.BecomeKinematic()`；恢复动态用 `br.SetLocalInertia(_wpInertia)`（该方法会同步 mobility）。
4. **运动学体"推动"工件必须按速度驱动**：只 `br.Pose = target` 瞬移、速度 0 → 接触求解按零速度处理，推不动工件。应 `br.Velocity.Linear = (target - current)/dt`，让积分器带它移动。本工程 `SetKinematicPose(handle,pos,rot,dt=1/60)` 已按此实现。
