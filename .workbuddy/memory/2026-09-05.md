## BepuPhysics v2 关键 API 踩坑（headless 验证时发现，真会导致运行时崩溃/NaN/不联动）

1. **`new SolveDescription()` 非法**：结构体默认全 0 → `SubstepCount=0` → `Simulation.Create` 抛 "Substep count must be positive"。必须用 `new SolveDescription(velocityIterationCount:1, substepCount:1)` 即 `new SolveDescription(1,1)`。
2. **`PairMaterialProperties` 默认 `SpringSettings` 致 NaN**：`new PairMaterialProperties()` 的 `SpringSettings` 默认频率 0/阻尼 0，物体一接触求解器除零→位姿 NaN。必须在 `ConfigureContactManifold<TManifold>` 内显式 `pairMaterial.SpringSettings = new SpringSettings(30f,1f);`（需 `using BepuPhysics.Constraints;`）。
3. **运动学↔动态切换不能靠 `BodyReference.LocalInertia = x`**：`LocalInertia` 是 ref 返回属性，赋值只写回惯性结构体、**不会**更新 `Collidable.Mobility`，导致运动学→动态切不回去（拖拽松手工件不落）。正确：运动学用 `br.BecomeKinematic()`；恢复动态用 `br.SetLocalInertia(_wpInertia)`（该方法会同步 mobility）。
4. **运动学体"推动"工件必须按速度驱动**：只 `br.Pose = target` 瞬移、速度 0 → 接触求解按零速度处理，推不动工件。应 `br.Velocity.Linear = (target - current)/dt`，让积分器带它移动。本工程 `SetKinematicPose(handle,pos,rot,dt=1/60)` 已按此实现。

## Sim3DView 机台全刚体碰撞 — 完成

需求（用户原话）：**"物体都需要是刚体，需要碰撞，不然蓝色物体一直掉落"**。上一轮仅有"兜底地面"单个静态碰撞体，工件会穿过机台部件继续下落。本轮让**每个机台部件都参与碰撞**。

- **静态碰撞体（`PhysicsWorld.AddFloor`）**：
  - 床身 `Box(130,4,90)@(0,-12,0)`；
  - 4 底脚 `Box(10,10,10)@(±55, -18, ±35)`；
  - 相机：机身 + 支架（按 `Cameras.Count`/`_usesCamera` 计算位置）；
  - 转台：每 `RotaryInfo` 两件 `Box(18,3,18)@(0,-9,0)` + `Box(16,4,16)@(0,-6,0)`；
  - 气缸缸体：每个 `CylLayout` `Box(9,16,9)@(cx,-4,cz)`。
- **运动学碰撞体（`AddKinematic` + 每帧 `SetKinematicPose`）**，按 `_dispX/_dispY/_dispZ` 与气缸状态驱动：
  - 龙门 3 件（`gantryL/gantryR` 随 X 轴, kind0；`gantryT` 随 X 轴, kind0）→ 局部坐标 lx/lz 偏置 + `_dispX`；
  - 桥式滑座（`bridge`, kind1）→ 随 X+Z（`_dispX`/`_dispZ`）；
  - 主轴/刀具（`spindleBody`+`spindleTip`, kind2）→ 随 X+Y+Z（`_dispX`/`_dispY`/`_dispZ`）；
  - 气缸活塞杆（`cyl:<name>`, kind3）→ 随伸出(1)/缩回(0) 竖直位移 `dy = st==1?0:-9`（取 `SimRuntime.GetCylinder`）。
  - 新增 `_kinSpecs` 列表 `List<(key,lx,ly,lz,sx,sy,sz,kind)>` 记录每个运动学体的局部基准与尺寸；`AddKinSpec` 同时登记到 `_physics.RegisterKinematic(key,h)`。
- **工件初始位姿** 由 y=-2 改为 y=-7（`Box(22,6,18)` 半高 3 + 床面 y=-10 → -7），与物理、视觉初始变换一致。
- **兜底地面**：`Box(500,4,500)@(0,-32,0)`，即使所有机台部件都没兜住，工件也不会无限下落。
- **`StepPhysics()` 重写**：遍历 `_kinSpecs`，按 `kind` 用对应位移量算世界位姿并 `SetKinematicPose`；最后 `_physics.Step(1/60)` 写回 `_workpieceModel.Transform`（Scale(22,6,18) + Rotate + Translate(pos)）。
